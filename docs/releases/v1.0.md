# 🪐 Astro 1.0

Your anime. Your manga. Your orbit.

**Android 12+ · Native Kotlin + Jetpack Compose · AniList**

Astro 1.0 is now a regular GitHub release. The installed app version is **1.0.0** (version code 3).

## Included

Mission Control, anime/manga/novel discovery, tracking and auto-sync support, profiles and charts, cast/voice actor pages, OP/ED episode coverage, schedule, twelve themes, chibi notices, standalone quiz, Stats/Wrapped, roulette, compatibility, constellations and JSON backups.

This release retains the 0.2 functionality and changes release/version metadata.

## Download

Install **Astro-1.0.apk** from Assets. Repository access is required.

**Signing:** this APK uses the existing debug signing pipeline. Long-term release signing is not configured, so Android may reject an upgrade over an earlier build. Back up from 0.2 first. Do not uninstall 0.1 if its local progress matters; it has no export UI.

## AniList setup

Create a separate native client with redirect `astro://oauth/anilist`, then enter its public client ID in Profile → Set up native login. Leave website client **50387** unchanged. Do not enter a client secret.

## Testing after release

The underlying 0.2 code passed 15 unit tests and 3 Android 12 instrumentation tests, with zero lint errors. This 1.0 packaging build checks compilation, APK version, signature and checksum. Additional phone, live-account sync, notification and battery tests are deferred until after this release at the owner's request.

The regular-release designation is a distribution choice; those remaining tests have not yet passed. See [the acceptance checklist](https://github.com/Bandit4420/Astro/blob/release/v1.0/docs/DEVICE_ACCEPTANCE.md).
