# Astro 1.2 — Make yourself at home

A native UI refresh based on Bandit's phone testing of 1.1.1.

## Fixed and hardened
- Birthday, age, gender and native names have separate layout containers; biography fields no longer overlap.
- Native Markdown/HTML biographies preserve paragraph breaks, bold text and tappable web links. About images remain supported. Unsafe/non-web links are ignored.
- Cast cards show voice-actor portraits beside their names. Character and staff pages retain their full galleries.
- OP/ED credits load when their section enters composition, remain together below cast, and retain episode ranges/counts. Requests cancel on navigation, are cached for six hours with a 24-title bound, and show a retry action on failure. No aggressive rate-limit retries.
- Schedule queries omit unused media-ID filters and fetch only the fields the calendar needs. An empty personal schedule never requests the entire catalogue.
- Profile identity/about, anime stats, manga stats and favorites load independently. A failed statistics section shows its own warning instead of blanking the entire profile or inventing zero totals. Anime and manga request type-appropriate fields.

## Appearance and feel
- New visual theme previews and grouped appearance controls.
- AMOLED is now an independent pure-black option across presets.
- Interface, filled/outlined button and navigation accents can be chosen separately, including custom hex colors.
- Floating rounded navigation; consistent heading/body typography and Modern/System/Serif heading options.
- Real Haze backdrop blur on navigation surfaces on supported Android versions, alongside translucent cards and blurred ambient artwork. Android 12/API 31 uses Haze's stable translucent navigation fallback; it is not a refraction simulation.
- Page entrance motion, spring button feedback and short artwork fades. All respect the animations setting; no perpetual decorative animation.
- Optional high-refresh display request, released in the background and suppressed in Battery Saver. Android/device policy can override it; this does not certify 120 fps.
- Battery Saver suppresses blur and animation; countdown timers pause in the background. The redundant startup discovery request is removed and image requests are remembered across recompositions.
- Consistent Liquid Glass/Midnight Blue/Golden Hour naming; Settings reads the installed app version instead of an old preview label.

## Validation and limits
Unit regression tests cover schedule filtering, partial profiles, music episode coverage/cache and rate limits. Instrumentation checks biography layout/link spans, primary navigation, migration and sync acknowledgements; device jobs target Android 12 and Android 15 with networking disabled.

Bandit's phone testing confirmed install, sign-in, collection loading, sync in both directions, auto-sync, collection controls and offline/restart on **1.1.1**. Those results are not a substitute for checking the changed screens in 1.2.

Live profile, schedule and OP/ED success remains a phone acceptance check. Provider HTTP 500/403 failures cannot be certified fixed by offline tests. Sustained frame pacing, heat, notification delivery and battery measurements remain unverified. A three-minute battery sample is not a controlled drain benchmark.

## Install
Android 12+, version code 7. Download **Astro-1.2.0.apk** and its SHA-256 checksum.
The existing package and temporary debug-signing pipeline are retained. Back up before any uninstall/reinstall; permanent signing is still pending.
