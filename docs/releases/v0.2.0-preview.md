# 🪐 Astro Android 0.2 — Your orbit grows

Native Android 12+ preview bringing Astro's main tracking and discovery workflows to your phone.

## What's new

- **AniList connection:** browser login, encrypted token storage, separate guest/account libraries, queued auto-sync and explicit conflict choices.
- **Mission Control:** continue watching/reading, next broadcast, catch-up calculator and recommendations with genre-overlap explanations.
- **Anime, manga & novels:** richer explore filters, studio search, pagination up to 80 titles, chapter/volume counters, ratings and private notes.
- **Details:** paginated characters and Japanese voice actors, biographies and other works, OP/ED together below cast with episode coverage, compact staff credits, franchise connections and trailers.
- **Personal tools:** profile images and charts, Stats/Wrapped, standalone cover/clue/trivia quiz with streaks, roulette, compatibility and constellations.
- **Appearance & reminders:** twelve presets, dynamic accents, glass opacity, decorative background blur, cover controls, chibi notices, weekly schedule and calendar export.
- **Backup:** account-bound Android/website JSON import/export for collection, private notes, recorded history and quiz progress. Tokens are never exported.

## AniList login setup

Create a separate **Astro Android** application in [AniList developer settings](https://anilist.co/settings/developer), with redirect **`astro://oauth/anilist`**. Enter its **public client ID** in Astro → Profile → Set up native login.

Keep website client **50387** unchanged. No client secret is required. Native login and real-account synchronization still need end-to-end verification with the configured client.

## Installation and preview limits

Download **Astro-0.2.0-preview.apk** below. Android 12 or newer is required.

This is a **debug-signed preview**, not a production release. A different CI signing key can prevent upgrading over 0.1. **Do not uninstall 0.1 if you need its local progress**: it has no backup UI. Keep it installed until a safe migration is available. Version 0.2 supports backups for future migrations.

Android controls notification delivery and may delay background work. Real-phone notification, glass rendering and battery testing remain pending. AniList does not supply reliable episode-level spoiler boundaries or manga chapter release timestamps; spoiler protection uses explicit reveal controls.
