# 🪐 Astro Android — First Native Preview

Your anime. Your manga. Your orbit. Now on Android.

**Development prerelease for Android 12 and newer.** This is the same verified APK from the first successful Android build, published here for direct download.

## Included

- Native Kotlin / Jetpack Compose interface with Orbit, Explore, Collection, Schedule and Settings.
- AniList anime, manga and novel discovery, search and pagination up to 80 titles.
- Local episode/chapter tracking with +1/−1 controls, statuses and collection statistics.
- Weekly airing schedule, Only my anime filtering, and local/IST times.
- Title pages, first 25 characters, Japanese voice actors, biographies and external trailers.
- Five dark themes, artwork accents across the UI and conservative spoiler protection.
- Opt-in Android episode notifications with background scheduling and duplicate suppression.

## Install

Download **Astro-0.1.0-preview.apk** under Assets and open it on your Android device. Allow installation from that download source if Android asks.

If you already installed the APK from Actions build #8, this is the identical binary and does not require an update.

## Preview limits

- **AniList login and auto-sync are not implemented yet.** Collection changes stay on this device.
- Device/emulator testing, actual notification delivery and battery/memory profiling remain pending.
- This is a debug-signed universal APK, package `com.bandit.astro.preview`, version `0.1.0-preview-debug`.
- Future preview builds may use a different debug signing key and require uninstalling, which deletes local progress. Stable release signing and backup/export are planned.
- OP/ED credits, quiz, advanced filters, chibi notices and remaining web features are still being ported.
