# Astro 1.0.1 — AniList login and readable text

## Fixed
- Sign in with AniList is available immediately, without entering a client ID.
- Login opens Astro's website handoff, uses its registered AniList application, then returns to the Android app through **Open Astro**.
- The browser request and app request have separate, expiring random state values. The app verifies the returned AniList Viewer before saving the encrypted session.
- Tokens stay in URL fragments during the handoff and are not stored as a website login session by this flow.
- Explicit light text colour for the transparent app container fixes the default black-text fallback reported in issue #4.
- An optional custom Android client remains under Advanced login settings.

## How to sign in
1. Open Profile → **Sign in with AniList**.
2. Tap **Continue with AniList** in your browser and authorize Astro.
3. Tap **Open Astro**, then **Sync now** to import your collection.
4. Enable Auto-sync if wanted.

No new native client registration is required for the default flow. Website client 50387 is unchanged.

## Validation and limitations
The website's six account/profile/handoff tests pass, including state mismatch, expiry and no web-session creation for the Android handoff. The website build succeeds. The Android workflow runs unit tests and compiles the APK, then verifies package/version, signing and checksum.

Real AniList account authorization and return-to-app behavior still require phone verification. Notifications and battery testing remain pending. This release does not claim those checks passed.

The existing temporary debug signing pipeline remains in use. Export your backup from 0.2/1.0 before installing if Android requires a reinstall. Do not uninstall 0.1 if its unexported local progress matters.
